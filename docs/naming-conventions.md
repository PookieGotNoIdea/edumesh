# Naming Conventions

To maintain consistency throughout EduMesh, the following conventions will be followed.

## JavaScript Variables and Functions
- Use camelCase.
- Use meaningful names.

## React Components
- Use PascalCase.
- Use descriptive component names.

## Database Tables
- Use consistent table naming.
- Keep column names descriptive.

## Files and Folders
- Use clear and meaningful names.
- Follow consistent naming patterns.
