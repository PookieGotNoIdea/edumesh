# EduMesh Database Design

EduMesh uses PostgreSQL as its relational database.

The database is designed to organize academic resources, user activities and learning progress.

## Main Database Entities

- Users
- Roles
- User Roles
- Subjects
- Topics
- Resource Types
- Resources
- Resource Reviews
- Resource Ratings
- Quizzes
- Questions
- Question Options
- Quiz Attempts
- Quiz Answers
- Study Tasks

## Database Design Principles

- Use primary keys to uniquely identify records.
- Use foreign keys to maintain relationships.
- Apply appropriate unique and check constraints.
- Reduce unnecessary data duplication.
- Follow normalization principles.
- Maintain data consistency and referential integrity.

The database schema will be refined as the application requirements and workflows are finalized.
